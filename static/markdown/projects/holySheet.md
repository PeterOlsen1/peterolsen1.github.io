### Problem Scope

This project was was created as an assignment for UMN's course,
CSCI 5117. We were challenged with creating an app that is used by singular users
for storing and interacting with data. Seeing that two of our four group members were musicians,
we decided to create a sheet music storage + editing app. However, we were required
by the class to utilize a new framework, which in this case was Ember.js. Nobody really
uses ember in production, so it was somewhat of a curveball. However, a good 
programmer should not let the tech stack get in the way of their development.

### Technologies

As mentioned previously, we used Ember.js for the frontend in this project.
Although somewhat obsolete, it was an extremely developmental experience
to pick up a new framework in such a short amount of time and create a fullstack
app with it. Additionally, Ember follows the MVC (model view controller) protocol,
which was very insightful to learn for future developmental practices. Although I would have
preferred to be assigned a more modern framework like Vue or Next, Ember was still sufficient.

As for the backend, we were assigned to use Firebase. Also mention azure for image storage.
