## Why a load balancer

Network programming has always been a very fascinating subject to me.
The interfaces that run behind every communication between computers are woefully neglected, but rightfully important.
Having taking an operating systems course last semester, 
I became increasingly more interested in programming the systems that run in the background, but power the entire internet.

All that to be said, I decided to try my hand at programming one such system, which led me to creating a load balancer.
This project has been a test of my system design muscles, and has been great for really diving deeper into what it means to
create scalable, secure, error-proof systems.
